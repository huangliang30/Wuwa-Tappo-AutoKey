# Wuwa Tappo 自动按键

一个 Windows 桌面自动连点（按键）器：按用户设定的频率向系统发送指定按键
（默认 **F15**），不动鼠标、不输入文字。适用于需要重复按键的桌面软件、
改键工具测试等场景。

> 统计数字为本程序实际调用系统按键接口（SendInput）的发送次数，
> **不一定等于目标应用实际接收的次数**。本工具不绕过任何反作弊或安全限制，
> 请自行确认目标软件允许接收模拟按键。

## 功能一览

| 分类 | 功能 |
| --- | --- |
| 自动按键 | 默认 F15，可选鼠标左/右/中键（在指针当前位置点击）或 F1~F24；目标次数最大 100,000,000；默认 500 次/秒（1~5000 可调） |
| 任务控制 | 开始 / 暂停 / 继续 / 停止 / 测试 100 次（以 25 次/秒发送，便于观察目标程序是否有反应） |
| 全局快捷键 | `Ctrl+Alt+F8` 暂停/继续，`Ctrl+Alt+F9` 停止（软件不在前台也有效） |
| 实时统计 | 已发送/目标总数、状态、本轮平均速度、预计剩余时间、进度百分比、进度条 |
| 参数设置 | 按键 / 次数 / 频率可保存、自动加载、一键恢复默认 |

## 快速开始

### 方式一：一键运行（推荐）

1. 安装 [Python 3.11+](https://www.python.org/downloads/)，安装时勾选
   **Add python.exe to PATH**；
2. 双击 `build.bat` —— 会自动安装依赖并启动程序。

### 方式二：手动运行

```bat
pip install -r requirements.txt
python main.py
```

## 打包为 EXE

双击 `build_exe.bat`，完成后得到：

```
dist\WuwaTappo自动按键.exe
```

- 单文件模式（`--onefile`），不显示命令行黑窗（`--windowed`）；
- 目标电脑**无需安装 Python**；
- 单文件 EXE 首次启动需要解压，等待 2~5 秒属正常现象。

### 常见打包问题

| 问题 | 解决办法 |
| --- | --- |
| 杀毒软件报毒 / 拦截 | 把项目目录加入白名单；或改用 `--onedir` 模式（把命令中 `--onefile` 换成 `--onedir`） |
| 打包后闪退 | 在命令行里以 `python main.py` 先确认能正常运行；再用 `--windowed` 去掉、带控制台打包查看报错 |
| 提示找不到 PyInstaller | `python -m pip install pyinstaller` 后重试 |
| 打包体积大（约 45~50MB） | PySide6 自带完整 Qt，属正常现象；可用 `--exclude-module` 裁剪不需要的模块 |

## 使用说明

1. **设置参数**：选择目标按键（默认 F15）、目标总次数（1 ~ 1 亿）、每秒按键数（1 ~ 5000）；
2. **开始任务**：点击「▶ 开始任务」，程序按设定频率发送按键；
3. **测试 100 次**：先小批量验证目标程序能否收到按键；
4. **暂停 / 继续**：点击按钮或按 `Ctrl+Alt+F8`，从暂停位置继续，计数不丢失；
5. **停止**：点击按钮或按 `Ctrl+Alt+F9`；停止后如需重新开始请再次点击「开始任务」；
6. **统计区**：实时显示已发送次数、平均速度（本轮实际运行时间折算，不含暂停）、
   预计剩余时间与进度条；剩余时间随实际速度动态变化。

### 提示与排错

- **目标程序收不到按键**：
  - 先用「测试 100 次」并在记事本等程序里验证（F13~F24 在记事本无可见效果，
    可临时换成 F5 刷新网页来验证）；
  - 目标程序以**管理员权限**运行时，普通权限程序发送的按键会被系统拦截
    （UIPI 机制）——此时请**以管理员身份运行本程序**；
  - 部分游戏仅接受硬件级输入或带驱动级防护，模拟按键无效，本工具不做绕过。
- **实际速度达不到设定值**：注入速度受系统输入管线限制（安全软件、低级键盘钩子、
  系统版本都会影响，本机实测约 200~240 次/秒上限）。程序会自动批量合并发送以尽量
  逼近设定值，统计区显示的「本轮平均速度」就是真实速度；
- **状态显示「运行异常」**：系统连续 5 次拒绝注入按键（错误码 5 多为权限问题），
  任务自动终止，按上面第 2 条处理。
- **快捷键无效**：可能被其他软件占用，界面会提示；仍可使用界面按钮。
- **配置文件位置**：`%APPDATA%\WuwaTappoAutoKey\config.json`，可直接删除以重置。

## 技术要点

- **不阻塞界面**：按键发送在独立工作线程执行，界面通过 100ms 定时轮询线程安全的
  统计快照刷新；
- **高精度节拍**：任务运行期间调用 `timeBeginPeriod(1)` 提升系统计时精度，
  采「粗睡眠 + 微自旋」混合等待，兼顾频率精度与 CPU 占用；
- **线程安全**：暂停/继续/停止基于事件与锁实现，防止重复启动与竞态；
  退出时停止任务、等待线程结束、注销热键，不留后台残留；
- **大数值安全**：Python 原生整数无溢出，进度条内部使用万分比避免浮点抖动。

## 关于「模拟输入是否算真实输入」

本工具通过系统标准接口 `SendInput` 注入输入：

- 对**绝大多数程序**（读窗口消息、`GetAsyncKeyState`、Raw Input 的应用），
  注入的鼠标点击/按键与真实硬件输入**无法区分**，会被正常接收和计数；
- 少数程序会在低级钩子里检查「注入标志」（`LLKHF_INJECTED`）并**故意忽略**
  模拟输入——这是对方的主动防护。要骗过它需要安装内核级驱动伪造硬件输入
  或使用硬件设备，属于绕过防护，本工具**不做**；
- 遇到这类程序时，请使用其自带设置或硬件方案。
